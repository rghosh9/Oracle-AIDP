Get Agent Flow Session trace for a given message key

get

/20240831/aiDataPlatforms/{aiDataPlatformId}/workspaces/{workspaceKey}/agentFlowSessions/{agentFlowSessionKey}/traces/{traceKey}

Returns trace details for a given message key.

Request

Path Parameters
  • agentFlowSessionKey(required): string
    The UUID of the Agent Flow Session
  • aiDataPlatformId(required): string
    The [OCID](/iaas/Content/General/Concepts/identifiers.htm) of the AI Data Platform (Data Lake) instance.
  • traceKey(required): string
    A filter to return only resources that match the given display trace key exactly.
  • workspaceKey(required): string
    The key of the Workspace
Header Parameters
  • opc-request-id: string
    Unique Oracle-assigned identifier for the request. If you need to contact Oracle about a particular request, please provide the request ID. The only valid characters for request IDs are letters, numbers, underscore, and dash.
