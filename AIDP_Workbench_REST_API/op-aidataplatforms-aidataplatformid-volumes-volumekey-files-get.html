Gets a list of files in the Data Lake Volume.

get

/20240831/aiDataPlatforms/{aiDataPlatformId}/volumes/{volumeKey}/files

Gets a list of Data Lake Volumes.

Request

Path Parameters
  • aiDataPlatformId(required): string
    The [OCID](/iaas/Content/General/Concepts/identifiers.htm) of the AI Data Platform (Data Lake) instance.
  • volumeKey(required): string
    The key of the Volume
Query Parameters
  • displayName: string
    Minimum Length: 1
    Maximum Length: 255
    A filter to return only resources that match the given display name exactly.
  • isRecursive: boolean
    A boolean which decides if nested files should be in the list files in volume response
    Default Value: false
  • limit: integer
    Minimum Value: 1
    Maximum Value: 1000
    For list pagination. The maximum number of results per page, or items to return in a paginated "List" call. For important details about how pagination works, see [List Pagination](/iaas/Content/API/Concepts/usingapi.htm#nine).
    Default Value: 100
  • page: string
    Minimum Length: 1
    For list pagination. The value of the opc-next-page response header from the previous "List" call. For important details about how pagination works, see [List Pagination](/iaas/Content/API/Concepts/usingapi.htm#nine).
  • path(required): string
    The absolute path of the file or folder
  • sortBy: string
    The field to sort by. You can provide only one sort order. Default order for `timeCreated` is descending. Default order for `displayName` is ascending.
    Default Value: timeCreated
    Allowed Values: [ "timeCreated", "displayName" ]
  • sortOrder: string
    The sort order to use, either ascending (`ASC`) or descending (`DESC`).
    Allowed Values: [ "ASC", "DESC" ]
Header Parameters
  • opc-request-id: string
    Unique Oracle-assigned identifier for the request. If you need to contact Oracle about a particular request, please provide the request ID. The only valid characters for request IDs are letters, numbers, underscore, and dash.
  • should-update-recent: boolean
    A flag to identify if the recent list should be updated.
    Default Value: false
