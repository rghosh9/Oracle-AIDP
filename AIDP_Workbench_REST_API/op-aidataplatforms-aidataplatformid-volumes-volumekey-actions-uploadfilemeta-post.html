Upload a file to Volume by generating par

post

/20240831/aiDataPlatforms/{aiDataPlatformId}/volumes/{volumeKey}/actions/uploadFileMeta

Create a Volume file by generating PAR or update metadata by close file. If file exists, then it will be updated.

Request

Path Parameters
  • aiDataPlatformId(required): string
    The [OCID](/iaas/Content/General/Concepts/identifiers.htm) of the AI Data Platform (Data Lake) instance.
  • volumeKey(required): string
    The key of the Volume
Query Parameters
  • isOverwrite: boolean
    A boolean which decides if overwrite is allowed
    Default Value: false
Header Parameters
  • opc-request-id: string
    Unique Oracle-assigned identifier for the request. If you need to contact Oracle about a particular request, please provide the request ID. The only valid characters for request IDs are letters, numbers, underscore, and dash.
  • opc-retry-token: string
    Minimum Length: 1
    Maximum Length: 64
    A token that uniquely identifies a request so it can be retried in case of a timeout or server error without risk of running that same action again. Retry tokens expire after 24 hours, but can be invalidated before then due to conflicting operations. For example, if a resource has been deleted and removed from the system, then a retry of the original creation request might be rejected.
  • path(required): string
    Minimum Length: 1
    Maximum Length: 255
    The absolute path of the file or folder
  • should-update-recent: boolean
    A flag to identify if the recent list should be updated.
    Default Value: false
