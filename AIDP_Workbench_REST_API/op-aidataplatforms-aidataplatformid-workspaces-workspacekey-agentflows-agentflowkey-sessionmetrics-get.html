Get session metrics for an agent flow

get

/20240831/aiDataPlatforms/{aiDataPlatformId}/workspaces/{workspaceKey}/agentFlows/{agentFlowKey}/sessionMetrics

Retrieves metrics data for the specified agent flow.

Request

Path Parameters
  • agentFlowKey(required): string
    The UUID of the Agent Flow
  • aiDataPlatformId(required): string
    The [OCID](/iaas/Content/General/Concepts/identifiers.htm) of the AI Data Platform (Data Lake) instance.
  • workspaceKey(required): string
    The key of the Workspace
Query Parameters
  • deploymentType: string
    A filter to return only resources whose value matches the given deploymentType.
    Default Value: TEST
    Allowed Values: [ "TEST", "DEPLOYMENT" ]
  • timeEnded(required): string(date-time)
    The end time for retrieving metrics
  • timeStarted(required): string(date-time)
    The start time for retrieving metrics
Header Parameters
  • opc-request-id: string
    Unique Oracle-assigned identifier for the request. If you need to contact Oracle about a particular request, please provide the request ID. The only valid characters for request IDs are letters, numbers, underscore, and dash.
  • should-update-recent: boolean
    A flag to identify if the recent list should be updated.
    Default Value: false
