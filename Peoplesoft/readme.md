## AI Data platform Implementation for Peoplesoft HCM and SCM data models.

This section illustrates - 
1. How AI Data platform can be used to build a Datawarehouse from **Peoplesoft (PSFT) subject areas** i,e HCM and SCM
2. **Synthetic data** can be generated for PSFT tables using OCI 26ai Synthetic data generation feature
3. **OCI Data catalog and API** to harvest PSFT data from multiple sources and assign custom properties
4. Filtering and processing PSFT jobs based on list of PSFT tables and other **parameters**
5. **Notification** using OCI Developer services integration for PSFT AIDP Workflows and jobs
6. **AIDP Medallion Architecture** (bronze, silver and Gold layer) implementation with PSFT
7. AI created Bronze, Silver and Gold data structures from PSFT tables
8. **Analytic views** and **ML Feature creation** based on PSFT tables
9. Mock Peoplesoft table structures and data is used for this purpose
